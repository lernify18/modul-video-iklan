# Caption iklan (CW) — format Ubai

```
<Satu ayat masalah dalam bahasa pembeli, tanpa emoji>

✅ <ciri 1 dari bahan>
✅ <ciri 2>
… (5–8 ciri, setiap satu fakta dari bahan)

<CTA ikut profil: «Klik butang di bawah» / Maps / komen KATA>
```

Variasi: 10 CW, setiap satu buka dengan masalah lain dari Peta Niche. Headline 5–7 perkataan; description satu ayat.
Tiada harga jika profil kata tidak. Tiada nombor telefon dalam teks.
